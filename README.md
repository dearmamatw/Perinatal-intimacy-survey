# 媽媽，妳睡了嗎？｜孕期親密關係「時光走廊」問卷

《媽媽，妳睡了嗎？》(Dear Mama) 第四集田野調查用的互動式問卷。
以「時光走廊」的闖關敘事，帶填答者回顧懷孕前、孕期、產後到此刻的親密關係經驗。
純前端單檔網頁，不記名，答案透過 Google Apps Script 寫入試算表。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 問卷本體。單檔網頁，手機瀏覽器可直接開。已內建送出網址。 |
| `apps-script.gs` | 後端程式碼，貼進 Google Apps Script，負責把答案寫入試算表。 |
| `設定說明_10分鐘搞定.md` | 手把手部署說明（開試算表、貼程式碼、拿網址、填回 HTML）。 |

## 部署方式

問卷本體 (`index.html`) 可放在任何靜態網頁空間：
- GitHub Pages（Settings → Pages → 選 branch）
- Cloudflare Pages（上傳 `index.html`，或連結此 repo）
- Netlify

後端 (`apps-script.gs`) 需部署為 Google Apps Script 網頁應用程式，
「誰可以存取」務必選「所有人」，並將部署後的網址填入 `index.html` 的 `SUBMIT_URL`。
詳見 `設定說明_10分鐘搞定.md`。

## 設計原則

- **不記名**：不收姓名、email、IP；引用數字時一律註明「非隨機抽樣、不代表全體」。
- **可跳過**：任何一題都能跳過，敏感題不施壓；區分「不適用」與「不想說」。
- **18 歲守門**：涉及成人親密關係，未滿 18 歲無法繼續。
- **性別與形式包容**：性生活由填答者自行認定，涵蓋異性、同性、跨性別。

## 注意

- 改動**題目欄位結構**（新增/刪除題目、改欄位名）後，需清空試算表讓它重長標題列，並重新部署 Apps Script。
- 只改**選項內容**（欄位不變）則不需清表。
